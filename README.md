# 힐데베르트의 iPhone

소설 《블랙배저》의 등장인물 힐데베르트 탈레브의 휴대폰을 상상한 비공식 팬 창작 사이트입니다.
작품의 주요 전개에 관한 스포일러가 포함되어 있습니다.

## GitHub Pages에 올리기

1. 새 GitHub 저장소를 만들고 이 압축 파일을 풉니다.
2. index.html과 assets 폴더를 포함해 압축을 푼 내용을 저장소의 최상위에 올립니다.
3. 저장소의 Settings → Pages를 엽니다.
4. Source는 Deploy from a branch, Branch는 main, 폴더는 /(root)로 설정하고 저장합니다.
5. 배포가 완료되면 Pages 화면의 Visit site로 공유 주소를 확인합니다.

별도 빌드나 서버가 필요하지 않습니다. 폴더와 파일 이름을 그대로 유지해 주세요.
프로젝트 주소의 하위 경로에서도 이미지·글꼴·스크립트가 동작하도록 상대 경로를 사용합니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
